# For_Princess — Asali

یک تجربه‌ی تعاملی و عاشقانه‌ی فارسی، ساخته‌شده با React و Vite.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس `http://127.0.0.1:5173` را باز کنید.

## ویرایش متن‌ها

تمام سؤال‌ها، گزینه‌ها، واکنش‌ها و متن‌های مرحله‌ی اعتراف در `src/content.js` قرار دارند. منطق مراحل در `src/App.jsx` و تمام جزئیات بصری و انیمیشن‌ها در `src/styles.css` هستند.

## خروجی نهایی

```bash
npm run build
```

نسخه‌ی قابل انتشار در پوشه‌ی `dist` ساخته می‌شود.
